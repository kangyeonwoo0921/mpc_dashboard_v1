## 2. 규칙

열림 % 기준 (100 = 걷힘, 0 = 완전 펼침). 우선순위: 안전 > 밤 보온 > 낮 차광 > 빛 보존.

**차광커튼2 (알루미늄 70%)**

| 상태 | 조건 | 추천 |
|---|---|---|
| 안전 우선 | 현장 상태 감우 또는 강풍 ON | 현재 위치 유지 (+ 천창 닫힘 권장 안내) |
| 밤 보온 | 일몰 −1 h ~ 일출 +0.5 h, 모드 자동·저온기 | 80% 닫힘 (열림 20%) |
| 낮 차광 | 모드 자동·고온기, 아래 하이브리드 조건 | 펼침 (열림 0%) |
| 빛 보존 / 차광 불필요 | 그 외 | 걷힘 (열림 100%) |

하이브리드 조건 (단일 기준 T = 700 W/m², 지속 n = 15분):
- 펼침: 앞으로 n분 예측이 모두 ≥ T **또는** 최근 n분 측정 평균 ≥ T
- 걷음: 쓸 수 있는 정보(예측, 측정)가 모두 < T
- 마지막 추천 변경 후 최소 유지 시간(기본 15분, 잠정) 안에는 바꾸지 않음
- 측정값은 최신 측정이 15분 이내이고 예측 파일이 오래되지 않았을 때만 사용

**차광커튼1 (산광 10%)**: 일몰 −2 h ~ 일출 +2 h 이고 외기 < 15 °C 이고 모드가 고온기가 아니면 펼침, 아니면 걷힘. 외기 온도가 없으면 판단 불가.

**운영 모드**: 자동 = 밤 보온 + 낮 차광 모두 적용 / 고온기 = 밤 보온 끔 / 저온기 = 낮 차광 끔.

## 3. 근거와 검증

| 항목 | 근거 |
|---|---|
| 700 W/m² | 재배 가이드 순간 일사 600–700 W/m² 상한 (측정 기준 미상 → 외부 일사로 임시 해석) |
| 지속·최소 유지 | Altes-Buch, Quoilin, Lemort (2019), 13th Int. Modelica Conf., DOI 10.3384/ecp19157533: 잦은 전환 방지를 위한 proving time과 minimum time (보광등 사례, 값 미제시) |
| 단계적·분리 기준 | Greenhouses 라이브러리 문서: 보온 스크린 ON/OFF 일사 기준 분리, 단계적 개방 (보온 스크린 사례) |
| 차광은 최후 수단 | FAO (2013) Good Agricultural Practices for greenhouse vegetable crops, 4장 |
| 국내 사례 | KSBEC (2020) 29(3):306: 외부 일사 650 W/m² 이상 자동 차광 (오이 실험 조건) |
| 밤 보온·산광 | 8·10·12월 재배 가이드 (80% 닫힘, 일몰 −1 h/일출 +0.5 h, 산광 일몰 −2 h/일출 +2 h, 외기 < 15 °C) |

데이터 검증 (7/28–10/9, 센서 기준):
- 700 초과 구간의 84%가 10분 이내 (구름 순간 증강). 15분 지속만으로 동작 횟수가 약 1/4로 줄고 차광 시간은 거의 유지 (예측 완벽 가정). 이력 구간 700/600을 추가해도 동작 횟수는 거의 같음 → 단일 기준으로 충분.
- 실제 운영 예측(8/31–10/9 재현)은 최대 683 W/m²로 700에 도달하지 않음 (예측은 평균 쪽으로 매끄럽고, 센서가 한낮에 낮게 읽음). 예측만으로는 차광이 일어나지 않아 측정 조건을 함께 사용(하이브리드): 하루 약 0.55회 동작, 차광 시간 0.3%. 가을에는 10월 가이드("불필요한 차광 금지")에 부합. 한여름과 센서 보정 후 재검토 필요.

## 4. 화면 구성 (2026-10-12 개편)

검토에서 나온 구조적 문제 5개(계산 흐름 단절, 화면 분리, 3D에 예측 없음, 상태 신호 분산, 정보 위계)를 다음과 같이 반영.

| 문제 | 반영 |
|---|---|
| 계산 흐름 단절 | GHI를 Engerer2로 직달·산란 분리 → 레이트레이싱으로 작물면 직달광 W/m² 추정. 추천 응답 `crop_light`에 현재 위치 vs 추천 위치 직달광 평균 |
| 화면 두 개 분리 | 3D 뷰어 안에 "운영 요약" 패널(일사·예측 그래프, 스크린 추천, 작물면 빛, 상세 화면 링크). 뷰어 전체 한국어 (개발자 서랍만 영어) |
| 3D에 예측 없음 | 운영 요약의 "3D 미리보기" 지금/+15/+30/+45/+60분: 그 시각의 태양 위치 + 예측 GHI + 추천 스크린 위치로 태양·일조 지도 갱신. 하루 시각 슬라이더는 맑은 날 기하용으로 유지 |
| 상태 신호 분산 | 두 화면 공통 상태 표시줄 (`js/ops-status.mjs`, `css/ops-status.css`): 종합 상태 / 데이터 출처 / 수신 시각 / 일사 예측 / 추천 / "추천만 · 장치 제어 안 함" |
| 정보 위계 | 추천 화면 맨 위 "지금 할 일" 카드(동작 · 열림 % 이동 · 다음 변화 시각 · 대표 근거, 나머지 근거는 펼치기). 열림 % 막대 하나로 통일(왼쪽 펼침 0, 오른쪽 걷힘 100, 점 = 현재). 60분 계획은 계단 그래프. 설정은 접힌 "운영 설정"으로 |

공용 모듈: `js/rec-common.mjs`(그래프, 다음 변화, 문구), `js/ops-status.mjs`, `js/ops-panel.mjs`(뷰어 패널). 추천 화면도 뷰어와 같은 버전 관리(import map)를 쓴다.

## 5. 알려진 한계

- 일사는 센서 값 기준: 한낮에 실제보다 약 15–23% 낮게, 고도 20° 미만에서 높게 읽음. 기준값은 같은 센서 기준으로 적용.
- 실내 습도 센서 고장(99% 이상 고정) 동안 습도 관련 규칙(새벽 습도 배출, 산광 낮 규칙)은 없음.
- 스크린 위치 단계·이동 시간·현장 차광 설정값 미확인. 확인되면 설정에서 조정.
- 천창은 보조: 안전 상황 안내만.
- 작물면 빛은 직달광만: 피복·스크린 산란 투과율이 없어 산란광 미포함. 측창 커튼·방풍벽 광학값이 없어 그쪽을 지나는 칸은 미계산.
- 직달·산란 분리(Engerer2)는 1분 자료로 맞춘 계수이고, 맑은 날 모델은 원문(McClear)과 달리 Ineichen을 사용. 센서가 한낮에 낮게 읽으면 산란 비율이 크게(직달이 작게) 추정된다. 현장 직달·산란 측정이 없어 현장 검증은 불가.
- Yang4(Yang 2022 최고 성능)는 1시간 Engerer2 계산 방식이 Yang(2021) 원문에만 있어 보류.
- 설정 API에 인증이 없음(로컬 사용 전제). 외부 공개 배포 전 인증 필요.
